# Lobobodev's Homebrew Tap

Homebrew Cask tap hosting [CodexBarMenuBar](https://github.com/Lobobodev/CodexBarMenuBar).

## Install

```bash
brew install --cask Lobobodev/tap/codexbarmenubar
```

This automatically installs the [CodexBar CLI](https://github.com/steipete/CodexBar) dependency as well.

## Upgrade

```bash
brew upgrade --cask codexbarmenubar
```

## Uninstall

```bash
brew uninstall --cask codexbarmenubar
```
